## 🛠️ Compilation

To compile any of the `.tex` files locally:

```bash
pdflatex resume_v2.tex
```

Alternatively, you can open or copy the source code directly into [Overleaf](https://www.overleaf.com/) and compile in the browser without installing anything locally.
